Selectors

A rule is a selector plus declarations in braces. The selector decides which elements the declarations apply to.

p { color: navy; }Type: every p element
.card { }Class
#main { }ID: one element, and it's hard to override
* { box-sizing: border-box; }Universal: every element
[type="email"] { }Attribute (also ^= starts with, $= ends with, *= contains)
nav a { }Descendant: any a inside a nav
ul > li { }Child: direct children only
h2 + p { }Next sibling: the p right after an h2
h2 ~ p { }Later siblings: every p after an h2
h1, h2, h3 { }Selector list: style several at once

Pseudo-classes & pseudo-elements

Pseudo-classes select elements by state or position, like hovered or first. Pseudo-elements, written with two colons, style a part of an element or add generated content.

a:hover { }The pointer is over it
button:focus-visible { }Keyboard focus, not mouse clicks
li:first-child { }Also :last-child and :only-child
tr:nth-child(odd) { }Also even, 3n and 2n+1
input:checked { }Also :disabled and :required
input:user-invalid { }Invalid, but only after the user has interacted
:is(h1, h2, h3) a { }Matches anything in the list
:where(ul, ol) { }Like :is() but adds no specificity
.card:has(img) { }A .card that contains an img
p:not(.intro) { }Every p except .intro
.btn::before { content: "→ "; }Generated content before the element's own content
input::placeholder { }The placeholder text
::selection { background: gold; }Text the user has selected

Cascade & specificity

When rules conflict, the browser compares layers, then specificity, then source order. Inheritance passes text-related values like color and font down to children.

#nav .link:hover { }Specificity 1-2-0: ids, then classes and pseudo-classes, then types
.btn { color: blue; }
.btn { color: red; }Same specificity: the later rule wins
p { color: gray !important; }Beats normal declarations; use sparingly
@layer reset, base, components;Set the layer order: later layers win
@layer base { a { color: teal; } }Styles outside any layer beat every layer
.child { color: inherit; }Take the parent's value
.reset { all: unset; }Undo every property: inherit or go back to the default

Box model

Every element is a box: content, then padding, border and margin around it. Setting box-sizing to border-box makes width include the padding and border, which is easier to reason about.

.box {
box-sizing: border-box;Width includes padding and border
width: 300px;
max-width: 100%;Never wider than its container
padding: 1rem 2rem;Top and bottom 1rem, left and right 2rem
margin: 1px 2px 3px 4px;Clockwise: top, right, bottom, left
margin: 0 auto;Centers a block that has a width
border: 1px solid #ccc;
border-radius: 8px;
outline: 2px solid blue;Like a border, but takes up no space
aspect-ratio: 16 / 9;
overflow: auto;Scrollbars only when the content overflows
margin-block: 1rem;Logical: top and bottom in horizontal text
padding-inline: 2rem;Logical: left and right in horizontal text
}

Units & math

Relative units scale with fonts, containers or the viewport, which makes layouts adapt. Math functions combine units and set limits so values stay within a sensible range.

font-size: 1.25rem;Relative to the root font size (rem)
padding: 0.5em;Relative to the element's own font size (em)
width: 50%;% of the containing block
height: 100dvh;Dynamic viewport height (dvh): adjusts for phone toolbars
max-width: 65ch;The width of a "0" (ch); good for limiting line length
width: calc(100% - 2rem);Math with mixed units
font-size: clamp(1rem, 2.5vw, 2rem);A preferred value, kept between a minimum and a maximum
width: min(100%, 600px);The smaller value (max() gives the larger)

Colors

CSS accepts colors in several notations. oklch() is useful for building palettes, because equal steps in lightness look equal to the eye.

color: #1e90ff;Hex: #rgb, #rrggbb or #rrggbbaa
color: rgb(30 144 255 / 50%);Red, green, blue, then alpha after the slash
color: hsl(210 100% 56%);Hue, saturation, lightness
color: oklch(65% 0.2 250);Lightness, chroma, hue
color: color-mix(in oklch, blue 70%, white);Blend two colors
border-color: currentColor;The element's text color
color: light-dark(#111, #eee);Light or dark value, following color-scheme
color-scheme: light dark;The page supports both; needed for light-dark()
background: transparent;

Typography

Fonts are picked from a list, using the first one that's available. Unitless line heights and rem sizes keep text proportional when users change their font size.

font-family: "Inter", system-ui, sans-serif;First available wins; end with a generic family
font-size: 1rem;
font-weight: 600;100 to 900: 400 is normal, 700 is bold
line-height: 1.5;Unitless: scales with the font size
letter-spacing: 0.02em;
text-align: center;
text-transform: uppercase;
text-decoration: underline wavy red;Line, style and color
text-wrap: balance;Even line lengths, for headings
text-wrap: pretty;Avoids a single word on the last line; ignored where unsupported
.truncate { overflow: hidden; text-overflow: ellipsis; white-space: nowrap; }Cut one line off with …
@font-face {Load your own font file
font-family: "Brand";
src: url("brand.woff2") format("woff2");
font-display: swap;Show a fallback font until it loads
}

Flexbox

Flexbox lays items out in one direction, a row or a column, and shares the space between them. It suits toolbars, navigation and anything that lines up along one axis.

.row {
display: flex;Children line up in a row
flex-direction: column;Or row (the default), row-reverse, column-reverse
justify-content: space-between;Spacing along the main axis
align-items: center;Alignment across it
flex-wrap: wrap;Allow more than one line
gap: 1rem;Space between items
}
.item { flex: 1; }Grow to share the free space equally
.item { flex: 0 0 200px; }Grow, shrink, basis: stays at 200px
.item { align-self: end; }Override align-items for one item
.item { order: -1; }Move it first visually (not for screen readers)

Grid

Grid lays items out in rows and columns at the same time. Use it for page layouts and card grids, where things need to line up both ways.

.grid {
display: grid;
grid-template-columns: repeat(3, 1fr);Three equal columns; fr shares the free space
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));As many 200px+ columns as fit
gap: 1rem 2rem;Row gap, then column gap
}
.wide { grid-column: span 2; }Take up two columns
.hero { grid-column: 1 / -1; }From the first column line to the last
.page {
display: grid;
grid-template-columns: 200px 1fr;
grid-template-areas:Name the regions, then place items by name
"header header"
"nav main";
}
header { grid-area: header; }
.center { display: grid; place-items: center; }Center content both ways
.child { display: grid; grid-template-columns: subgrid; }Use the parent grid's columns

Positioning

Positioning takes an element out of the normal flow or pins it in place. Absolute positions are measured from the nearest positioned ancestor, so set position: relative on the parent.

.parent { position: relative; }The reference point for absolute children
.badge { position: absolute; top: 0; right: 0; }Placed against the nearest positioned ancestor
.bar { position: sticky; top: 0; }Scrolls normally, then sticks at the top
.toast { position: fixed; inset: auto 1rem 1rem auto; }Pinned to the viewport; inset is top, right, bottom, left
.modal { z-index: 10; }Stacking order of positioned, flex and grid items
.card { isolation: isolate; }Keeps its children's z-index inside it
.trigger { anchor-name: --menu; }Anchor positioning (in all major browsers since 2026)
.menu { position: absolute; position-anchor: --menu; position-area: bottom; }Placed below the anchor
.gone { display: none; }Removed from the layout
.ghost { visibility: hidden; }Invisible, but still takes up space

Responsive design

Media queries adapt styles to the screen and the user's settings, and container queries adapt a component to the space it's given. Start with the small-screen styles and add queries for wider screens.

@media (width >= 600px) { }Range syntax, same as (min-width: 600px)
@media (600px <= width <= 900px) { }Between two widths
@media (prefers-color-scheme: dark) { }The user's light or dark setting
@media (prefers-reduced-motion: reduce) { }The user asked for less animation
@media (hover: hover) and (pointer: fine) { }A mouse or similar
@media print { }
.wrapper { container-type: inline-size; }Make it a size container
@container (width > 400px) {Styles based on the container's width, not the viewport's
.card { display: flex; }
}
img { max-width: 100%; height: auto; }Images shrink to fit their container

Custom properties & nesting

Custom properties are variables that cascade and inherit like any other property, so you can override them for one part of the page. Nesting groups related rules inside their parent.

:root { --brand: #0b5fff; --gap: 1rem; }Define them, usually on :root
.btn { background: var(--brand); }Use one
.btn { padding: var(--pad, 0.5rem); }A fallback for when it isn't set
.dark { --brand: #7aa2ff; }Override it for part of the page
@property --angle {A typed custom property, which can be animated
syntax: "<angle>";
inherits: false;
initial-value: 0deg;
}
.card {Nesting
padding: 1rem;
&:hover { background: #f5f5f5; }& stands for the parent selector
.title { font-weight: 700; }Same as .card .title
@media (width >= 600px) { padding: 2rem; }
}

Transitions & animations

Transitions animate a change from one value to another, like a hover. Animations run through keyframes on their own and can loop.

.btn { transition: background-color 0.2s ease, transform 0.2s; }Animate changes to these properties
.btn:hover { transform: translateY(-2px); }
.icon { rotate: 45deg; scale: 1.2; translate: 0 4px; }Individual transform properties
@keyframes spin {The named steps of an animation
from { rotate: 0deg; }
to { rotate: 360deg; }
}
.loader { animation: spin 1s linear infinite; }Name, duration, easing, repeat
.popup { transition: opacity 0.3s, display 0.3s allow-discrete; }Lets display: none animate too
@starting-style { .popup { opacity: 0; } }Where the transition starts when it first appears
