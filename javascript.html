Variables & data types

Variables hold values, and the type belongs to the value rather than the variable, so one variable can hold different types over time. Use const by default and let when you need to reassign; var is the older, function-scoped form.

console.log("Hello World");Print to the console
let a = 1, b = 2;Block-scoped, can be reassigned
const PI = 3.14;Block-scoped, can't be reassigned
var old = 12;Function-scoped (legacy)
typeof a;"number"
obj instanceof MyClass;True if obj was built from MyClass or a subclass of it
void 0;Always evaluates to undefined

Errors & debugging

An error stops normal execution until something catches it. try/catch handles errors where you choose, and finally runs cleanup either way.

Async

Some work, like a network request, finishes later. A Promise stands for that future result, and async/await let you wait for it in code that reads top to bottom without blocking the page.
