Cheat sheets

CSS

The language that styles HTML: colors, fonts, spacing, layout and animation, adapting to any screen size.

GraphQL

A query language for APIs and a runtime for executing those queries with your existing data.

HTML

The markup that gives a web page its structure and meaning: headings, text, links, images and forms.

JavaScript

The programming language of the web. It makes pages interactive in the browser and runs servers and scripts through Node.js.

React

A JavaScript library for building interfaces out of components that update themselves when their data changes.

Shopify Liquid

Shopify's template language. It runs on Shopify's servers and turns store data like products and carts into a theme's HTML.

TypeScript

JavaScript with types. It checks your code for mistakes before it runs, then compiles to plain JavaScript.
